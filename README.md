# CRYSTAL QUEST

FINAL FANTASYをイメージした魔法を選び、自分の写真から戦闘シーンを作るためのGemini連携サイトです。アルテマ、フレア、ホーリー、サンダガ、ブリザガ、メテオの6種類を用意しています。初期選択はアルテマです。

[Webサイト](https://ku1220.github.io/gemini-prompt-launcher/) · [GitHub](https://github.com/ku1220/gemini-prompt-launcher)

**FF用プロンプトの自動入力・実行は、まだ接続されていません。** 公式ジェミニクエストではGoogleに登録されたプロンプトIDを使う起動リンクが確認できましたが、その既存IDはドラゴンクエスト用です。FF用IDの公開された登録方法は確認できていないため、現在は初回のみコピー・貼り付け・送信するモードです。

## 現在の使い方

1. 魔法を選び、プロンプトを準備します。
2. プロンプト全文をコピーしてGeminiを開き、入力欄に貼り付けて送信します。
3. 次の案内が表示されたら、Geminiの「＋」から写真を撮影または選択して送信します。

> 冒険の準備はできましたか？ 下の『＋』ボタンからカメラを起動し、まものに立ち向かう勇姿を撮影して送信してください！

プロンプトは、写真を受信するまで上記の案内だけを返し、受信後に選択した魔法の戦闘シーンを1枚だけ生成するよう指示します。人物の特徴と撮影されたモンスター立像の造形を保持し、現代の看板や建物はファンタジーの背景へ置き換える内容です。案内文の完全一致や画像の枚数・品質は、Geminiの実際のモデル動作まで保証するものではありません。

写真はGeminiへ直接送信します。このサイトは写真を受け取ったり、画像生成を代行したりしません。Gemini API、APIキー、独自の画像保存サーバーは使用していません。

## 自動スタートの接続点

`dist/launch-config.js` の `REGISTERED_PROMPTS` は、Google側で実際に登録されたFF用プロンプトの、魔法・端末別の検証済み完全URLを設定する接続点です。初期値はすべて `null` です。未設定の魔法は手動スタートになります。iOSでの確認をAndroidやWebの確認として扱わず、確認したURLを変更せず使用します。

既存のDQ用IDをFF用IDとして流用してはいけません。プロンプト本文を変更しただけでは、Google側の登録内容は変わりません。任意の `?q=` で自動入力できるという前提も使用していません。

実際の起動URL、調査根拠、未確認の範囲は [LINK-COMPATIBILITY.md](docs/LINK-COMPATIBILITY.md) を参照してください。

## ローカル実行と公開

Node.js 20以上を使用します。依存パッケージのインストールやビルドは不要です。

```sh
npm run check
npm start
```

`http://127.0.0.1:4173` を開きます。配信対象は `dist/` です。付属のGitHub Pagesワークフローは `main` へのpush後に検証し、同じディレクトリを公開します。

Geminiアプリの起動、自動スタート、撮影後の画像生成は、Android・iOSの実機で別途確認が必要です。ローカルの自動テスト成功は、実機での動作確認を意味しません。

Google、Gemini、FINAL FANTASY、スクウェア・エニックスの公式サービスではありません。
