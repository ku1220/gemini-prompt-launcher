# CRYSTAL QUEST

FINAL FANTASYをイメージした魔法を選び、Geminiへ送る写真クエスト用のプロンプトを準備するサイトです。アルテマ、フレア、ホーリー、サンダガ、ブリザガ、メテオの6種類を用意しています。初期選択はアルテマです。

[Webサイト](https://ku1220.github.io/gemini-prompt-launcher/) · [GitHub](https://github.com/ku1220/gemini-prompt-launcher)

## Mac用ローカル試作

Chrome拡張機能を事前に追加したPC用の、自動入力・送信ランチャーを追加しました。MacのChromeで、開始ボタンからアルテマの指示送信と指定の歓迎文の表示まで確認済みです。`Start Crystal Quest.command` または `npm run local` で起動します。[セットアップと制約](docs/LOCAL-LAUNCHER.md)を参照してください。公開サイトとスマートフォンのアプリ起動とは別の方式で、以下は公開サイトについての説明です。

**公開サイトのボタンだけで行う、スマートフォンアプリへの自動入力・自動実行は実現していません。** `?q=` 方式は利用者からAndroid・iOS・Webの全環境で入力されないとの報告があり、通常の開始導線から外しました。公開サイトで現在利用できるのは、本文を手動でコピー・貼り付け・送信する手順です。この手順を完全自動体験の達成とは扱いません。

## 現在の使い方

1. 魔法を選び、「アルテマを手動で準備」などのボタンを押します。
2. 本文を選択し、端末の「コピー」（PCでは⌘C / Ctrl+C）を使います。
3. Geminiを開き、本文を入力欄に貼り付けて送信します。
4. 次の案内が表示されたら、Geminiの「＋」から写真を撮影または選択して送信します。

> 冒険の準備はできましたか？ 下の『＋』ボタンからカメラを起動し、まものに立ち向かう勇姿を撮影して送信してください！

プロンプトは、写真を受信するまで上記の案内だけを返し、受信後に選択した魔法の戦闘シーンを1枚だけ生成するよう指示します。人物の特徴と撮影されたモンスター立像の造形を保持し、現代の看板や建物をファンタジーの背景へ置き換える内容です。案内文の一致、画像枚数、生成結果はGeminiのモデル動作まで保証するものではありません。

写真はGeminiへ直接送信します。このサイトは写真を受け取りません。Gemini API、APIキー、独自の画像保存サーバーは使用していません。

## 自動入力に残っている条件

Geminiが実際に受理する任意テキストの入力インターフェース、または正しいFF指示を登録した実行URLが必要です。現在、その動作確認済みの受け取り口を確保できていません。確認済みの公式イベント用IDはDQ用で、FF版には流用していません。

`prefilledQuestLink()` と関連テストは、過去に試した `q` URLのエンコード・全文保持を確認する診断用として残しています。通常のボタンからは使用しません。このテストの成功は、Gemini側の自動入力への対応を示しません。

確認した事実と調査資料は [LINK-COMPATIBILITY.md](docs/LINK-COMPATIBILITY.md) を参照してください。

## ローカル実行と公開

Node.js 20以上を使用します。依存パッケージのインストールやビルドは不要です。

```sh
npm run check
npm start
```

`http://127.0.0.1:4173` を開きます。配信対象は `dist/` です。GitHub Pagesワークフローは `main` へのpush後に検証し、同じディレクトリを公開します。

自動テストの成功は、Geminiへの自動入力や、実機での撮影後の画像生成成功を意味しません。

Google、Gemini、FINAL FANTASY、スクウェア・エニックスの公式サービスではありません。
