# Gemini Prompt Launcher

長文プロンプトを編集し、全文コピーとGoogle所有のHTTPSリンクでGeminiへ渡す、日本語の静的Webアプリです。APIキーは不要です。

**任意の長文をGeminiのネイティブアプリへ自動入力する公式URL仕様は確認できていません。** 通常は全文をコピーしてからGeminiを開き、入力欄へ貼り付けます。URLクエリによる入力は、対応を保証しない実験機能として分けています。自動送信は行いません。

公開先： [Webサイト](https://ku1220.github.io/gemini-prompt-launcher/) · [GitHub](https://github.com/ku1220/gemini-prompt-launcher)

## 使い方

1. プロンプトを入力するか、`.txt` / `.md` ファイルを読み込みます。
2. 全文をコピーし、表示されたリンクからGeminiを開きます。
3. Geminiの入力欄に貼り付け、内容を確認して送信します。

短いプロンプトでは「URLによる自動入力」を試せます。ただし、Gemini側がクエリを無視したり、アプリではなくブラウザで開いたりする場合があります。その場合も全文コピーを利用できます。

## 機能と制限

- 長文の編集、文字数・URLサイズの表示、テキストファイルの読み込み。
- Android / iOS / Webに応じたGeminiへのリンク。
- 自サイトの `?prompt=...` / `#prompt=...` による事前入力。共有にはフラグメント形式を優先します。
- 端末への保存は任意です。保存を有効にした場合のみブラウザのローカルストレージを使います。
- 入力上限は200,000 UTF-16コード単位です。長いURLによる実験は、生成したURLがUTF-8で8,000バイトを超えると無効になります。これはこのサイト独自の保守的な上限で、Geminiの公称制限ではありません。

プロンプト処理はブラウザ内で行います。独自のAPIサーバー、Gemini API、アクセス解析は使用しません。URLクエリを使うと、プロンプトがGoogleへ送られ、履歴やログに残る可能性があります。フラグメントは通常HTTPリクエストには含まれませんが、共有相手やブラウザ履歴からは読み取れます。

リンク仕様・対応表・実機確認項目は [LINK-COMPATIBILITY.md](docs/LINK-COMPATIBILITY.md) を参照してください。

## ローカル実行

Node.js 20以上を使用します。依存パッケージのインストールやビルドは不要です。

```sh
npm test
npm start
```

`http://127.0.0.1:4173` を開きます。配信対象は `dist/` です。

## GitHub Pagesへの公開

リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定し、`main` ブランチへpushします。付属のPagesワークフローが検証後に `dist/` を公開します。

```sh
git add .
git commit -m "Update prompt launcher"
git push
```

モバイルアプリの起動・入力はOS、ブラウザ、アプリのインストール状態や設定に依存します。デスクトップでの検証だけで実機対応済みとは扱いません。

GoogleまたはGeminiの公式アプリではありません。
