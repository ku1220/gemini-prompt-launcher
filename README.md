# CRYSTAL QUEST

FINAL FANTASYをイメージした魔法を選び、自分の写真から戦闘シーンを作るためのGemini連携サイトです。アルテマ、フレア、ホーリー、サンダガ、ブリザガ、メテオの6種類を用意しています。初期選択はアルテマです。

[Webサイト](https://ku1220.github.io/gemini-prompt-launcher/) · [GitHub](https://github.com/ku1220/gemini-prompt-launcher)

選んだ魔法のプロンプト全文をURLエンコードし、`https://gemini.google.com/app?q=...` へ渡す方式を実装しています。**送信はGemini側で行います。** このサイトから送信ボタンを自動操作したり、自動送信を指定したりはしません。Gemini API、APIキー、登録済みの `prompt_id` は不要です。

## 現在の使い方

1. 魔法を選び、「冒険をはじめる」からGeminiへ進みます。
2. Geminiの入力欄を確認し、プロンプトを送信します。本文が入力されていない場合は「入力されない場合の操作」で本文を選択し、端末の「コピー」を使ってGeminiへ貼り付けて送信してください。
3. 次の案内が表示されたら、Geminiの「＋」から写真を撮影または選択して送信します。

> 冒険の準備はできましたか？ 下の『＋』ボタンからカメラを起動し、まものに立ち向かう勇姿を撮影して送信してください！

プロンプトは、写真を受信するまで上記の案内だけを返し、受信後に選択した魔法の戦闘シーンを1枚だけ生成するよう指示します。人物の特徴と撮影されたモンスター立像の造形を保持し、現代の看板や建物はファンタジーの背景へ置き換える内容です。案内文の完全一致や画像の枚数・品質は、Geminiの実際のモデル動作まで保証するものではありません。

写真はGeminiへ直接送信します。このサイトは写真を受け取ったり、画像生成を代行したりしません。Gemini API、APIキー、独自の画像保存サーバーは使用していません。

## URLによる受け渡し

URLは次の形式で生成します。

```js
const targetUrl = `https://gemini.google.com/app?q=${encodeURIComponent(fullPrompt)}`;
```

入力内容を切り詰めず、日本語・改行・記号を含む全文を渡します。URLがUTF-8で8,000バイトを超える場合はコピーによる受け渡しを使います。この上限はサイト独自の保守的な設定で、GoogleやOSが公表した上限ではありません。既定の魔法6種類は上限内です。

Gemini側の入力欄への反映とアプリ起動は、端末、ブラウザ、アプリのバージョン、ログイン状態に依存します。URL生成の実装と、受け取り側での動作確認は分けて扱います。スマートフォン実機での起動・入力は未検証です。

URLにはプロンプト本文が含まれ、Googleへ送信されます。共有URL、ブラウザ履歴、ログから本文を読める可能性があるため、機密情報を含めないでください。

実際の起動URL、調査根拠、未確認の範囲は [LINK-COMPATIBILITY.md](docs/LINK-COMPATIBILITY.md) を参照してください。

## ローカル実行と公開

Node.js 20以上を使用します。依存パッケージのインストールやビルドは不要です。

```sh
npm run check
npm start
```

`http://127.0.0.1:4173` を開きます。配信対象は `dist/` です。付属のGitHub Pagesワークフローは `main` へのpush後に検証し、同じディレクトリを公開します。

Geminiアプリの起動、入力欄への反映、撮影後の画像生成は、Android・iOSの実機で別途確認が必要です。ローカルの自動テスト成功は、実機での動作確認を意味しません。

Google、Gemini、FINAL FANTASY、スクウェア・エニックスの公式サービスではありません。
