# Mac用ローカルランチャー（Chrome版・1.2.0）

ローカル画面で魔法を選び、写真を撮影・確認してから、魔法の指示と写真を新しいGeminiチャットへまとめて送信する試作です。サイトからGeminiへの移動は1回で、最初の送信から画像生成を依頼します。Gemini API、APIキー、Gem、スキルは使用しません。Geminiで画像生成を使えるアカウントとインターネット接続が必要です。

## 起動と初回設定

Node.js 20以上があるMacで、プロジェクト直下の `Start Crystal Quest.command` をダブルクリックします。または、このフォルダで `npm run local` を実行し、Chromeで `http://127.0.0.1:4174/` を開きます。

初回は `chrome://extensions` で「デベロッパーモード」をオンにし、「パッケージ化されていない拡張機能を読み込む」から、生成された `.local/crystal-quest-extension` フォルダを選びます。追加後にローカル画面を再読み込みしてください。

既に旧版を追加している場合は、次の順で更新します。

1. プロジェクトのフォルダで `npm run local:prepare` を実行します。
2. `chrome://extensions` の「Crystal Quest Local」で再読み込みボタンを押します。
3. ローカル画面も再読み込みし、1.2.0に接続した状態で使います。

## 撮影から生成まで

1. ChromeのGeminiにログインしておきます。
2. ローカル画面で魔法を選び、撮影へ進みます。この時点ではGeminiを開きません。
3. 「カメラを起動」を押してカメラを許可し、プレビューを見て撮影します。ブラウザの「今回のみ許可」でも利用できます。保存済みのJPEG・PNG・WebP画像を選ぶこともできます。
4. 写真と魔法を確認します。撮り直す場合はここでやり直し、よければ「この写真で生成」を押します。
5. 拡張機能が新しいGeminiチャットを開き、選んだ魔法の指示全文と写真を一緒に添付・送信します。歓迎文のための先行送信は行わず、そのまま画像生成を依頼します。
6. 新しいGemini回答に完成画像が1枚表示されたことを確認し、完了を知らせます。サイトに戻る必要はなく、画像の閲覧・保存はGeminiで行います。

撮影・写真選択だけではGoogleへ送信しません。「この写真で生成」を押すと、プレビューの写真がGeminiへアップロードされます。

カメラ映像にだけ適用していた鏡像表示を取り除き、ライブ映像・撮影後のプレビュー・Geminiへ送る写真を自然な左右の向きにそろえます。保存済み写真にも左右反転を加えません。

カメラ撮影は長辺1600px以下のJPEGにします。保存済み写真も読み込み後にJPEGへ再エンコードします。入力ファイルは8MiB以下、解像度は4000万画素以下に制限しています。マイクは要求しません。カメラは撮影後やページを離れた時に停止します。

## 権限とデータ

拡張機能の権限は1.0.0から増えていません。撮影時には、ローカルページへのカメラ許可が別途必要です。

- `scripting` と `https://gemini.google.com/*`：今回のクエスト用に開いた新規Geminiタブで、指示入力・写真添付・送信と生成結果の確認を行います。送信前は既存の会話や下書きがないことを確認し、送信後は今回作成された会話IDを確認します。別の会話へ変わっていたら停止します。
- `storage`：ブラウザセッション中、クエスト・会話・写真リクエストのID、進行状態や確認結果、写真のMIME・サイズ・SHA256などのメタデータだけを保持します。Cookie、パスワード、写真本体、会話本文を保存する処理はありません。
- 写真：送信に必要な間だけブラウザのメモリに保持します。ローカルサーバーやブラウザストレージには保存しません。ページを再読み込みした場合、未送信の写真は選び直しになります。
- ローカル画面のブリッジ：`http://127.0.0.1:4174/` の最上位ページだけから、決められた魔法IDと写真送信操作を受け付けます。公開サイト、別ポート、iframe、任意のURLやコードの実行は受け付けません。
- サーバー：127.0.0.1だけで待ち受け、HostとOriginを照合し、決められた静的ファイルだけを配信します。

## 中断・エラーの場合

Geminiが新規タブへ下書きや別の添付を復元した場合は、上書き・送信せず停止します。既存の会話にも送信しません。今回の指示を入力した後は全文を照合し、リッチテキスト編集による空行数の変化だけを許容します。

指示と写真をまとめた送信のリクエストIDで重複を防止します。写真の添付・送信が中断した場合や結果が不明な場合は、自動で再添付・再送せず、Geminiの確認を促します。送信済みの可能性があるため、画面を確認してから新しい冒険を開始してください。

指示と写真の送信だけを成功にせず、今回の会話で新しい回答の画像1枚を確認して完了にします。利用上限、生成エラー、異なる返答、画像が0枚・複数枚、確認のタイムアウトでは完了扱いにしません。Geminiの画面やモデル動作の変更によって止まる場合があります。ランチャーがモデルの画像内容や枚数を強制できるわけではありません。

## 対応範囲と開発

この試作はMacのChrome Web版向けです。SafariやスマートフォンのGeminiネイティブアプリには対応していません。公開サイトと、通常の `npm start` で開く手動導線は変更していません。公開・スマホ向けの歓迎文はそのままに、ローカル版だけ写真と指示を一括送信する内容を使います。

`local/extension/` が拡張機能、`local/web/` が撮影・起動画面のソースです。`npm run local:prepare` または `npm run local` が、正規の `dist/quest.js` とローカル版のソースを `.local/crystal-quest-extension/` にコピーします。依存パッケージは不要です。

停止は起動したターミナルでCtrl+Cです。Chrome拡張は登録済みのまま残ります。不要になったら `chrome://extensions` から削除できます。常駐・自動ログイン・バックグラウンド起動の登録は行いません。

`npm run check` はプロンプト、ローカルの境界、写真検証、送信の重複抑止などを確認します。自動テストの成功だけを、実際のGeminiでの画像生成成功とは扱いません。

## 実機検証の結果

1.2.0をMacのChromeで確認しました。FaceTimeカメラのライブ映像と撮影後プレビューの左右の向きは一致し、撮影後のカメラ停止も確認しています。撮影したカメラ写真はGoogleへ送らず破棄しました。

合成JPEGを使ったサンダガの検証では、新しいGeminiタブへ魔法の指示全文と写真を1つのメッセージで自動送信し、画像1枚の生成とローカル画面の完了状態まで確認しました。サイトへの自動戻りは発生しません。フレアでも一括送信から画像1枚の生成を確認しました。

自動テストは64件成功しています。他4種類はローカル用プロンプトの生成を自動テストで確認しており、写真からの画像生成と本人写真の特徴が忠実に保持されるかは未検証です。
